# AI Detector Bias Analysis

## Overview
A DS480 project examining whether GPTZero 5.0b misclassifies human-written TOEFL and US student essays as AI-generated. Includes 60 web scans, false-positive analysis, and historical score comparisons.


## Files
- **Analysis notebook:** Reproduces results from saved records.
- **Data Collection notebook:** Documents the scanning workflow.
- **data/**: Source corpus and selected essay IDs.
- **results/**: Recorded scans, tables, figure, and screenshots.

## Stack
Python · pandas · matplotlib · Google Colab

## Data Source
[Liang et al. (2023): ChatGPT Detector Bias](https://github.com/Weixin-Liang/ChatGPT-Detector-Bias)
